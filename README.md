# Mobile-app-of-the-St.-Petersburg-Phygital-Sports-Federation

## Описание проекта
Проект посвящен системному анализу, сбору требований и проектированию архитектуры клиентской части мобильного приложения для Регионального отделения «Федерация фиджитал спорта Санкт-Петербурга». 

Цель проекта — создать единое мобильное приложение для организации турниров: заменить разрозненные гугл-формы, почту и соцсети удобной системой для подачи заявок, загрузки и проверки документов участников.

## Этапы проекта

### 1. Анализ предметной области и стейкхолдеров
- Изучение текущих бизнес-процессов федерации и взаимодействия с регулирующими органами (Комитет по спорту, Центр спортивной подготовки).
- Выявление проблемных зон: ручная обработка заявок судейской коллегией, отсутствие прозрачности статусов допуска, риски потери персональных данных при пересылке сканов документов в мессенджерах.
- Сравнительный анализ систем-аналогов («Мой Фиджитал», «Weams», «ImGame») и обоснование необходимости разработки приложения.
- Выделение и профилирование 4 ключевых ролей пользователей: **Зритель**, **Спортсмен**, **Тренер** и **Организатор**.

### 2. Сбор и спецификация требований
- Разработка перечня функциональных требований: сквозная ролевая модель, подача индивидуальных и командных заявок, управление турнирами, модерация документов, просмотр регламентов в PDF без локального скачивания, формирование цифрового Phygital ID (QR-пропуск).
- Формирование нефункциональных требований: кроссплатформенность (Android/iOS), адаптивность интерфейса, интеграция с Notification API.

### 3. Моделирование бизнес-логики и архитектуры системы
- **Моделирование сценариев использования:** разработка диаграмм вариантов использования (UML Use Case) для всех ролевых моделей с разделением зон ответственности.
- **Инфологическое и объектное моделирование:** построение инфологической модели предметной области и диаграмм классов (UML Class Diagram) для распределения слоев данных, домена и представления.
- **Динамическое моделирование:** построение UML-диаграмм состояний (State Machine Diagram) для жизненных циклов заявок и документов, а также диаграмм последовательности (Sequence Diagram) для ключевых процессов.
- **Моделирование пользовательских потоков:** проектирование сценариев взаимодействия в нотации Райана Сингера (UI Flow Shorthand Notation) для подачи заявки спортсменом и модерации организатором.

### 4. Прототипирование и тестирование
- Создание интерактивных прототипов экранных форм приложения в Figma.
- Разработка тестовых сценариев и проверка требований в ходе приемочного функционального и нефункционального тестирования.

## Навыки и инструменты

### Навыки:
1. Анализ бизнес-процессов и сбор требований
2. Моделирование требований и системной логики (UML: Use Case, State Machine, Sequence, Class Diagrams)
3. Моделирование пользовательских переходов (UI Flow Shorthand Notation)
4. Инфологическое моделирование предметной области
5. Проектирование ролевых моделей доступа и жизненных циклов сущностей
6. Составление спецификаций и проектной документации
7. Функциональное и нефункциональное тестирование, проверка требований

### Инструменты:
- **Моделирование и нотации:** UML, UI Flow (нотация Райана Сингера), Draw.io
- **Прототипирование:** Figma
- **Документирование:** MS Word
- **Технологический стек реализации:** Flutter, Dart, Riverpod, Hive (NoSQL), Notification API

## Вывод

По итогам выполнения проекта системного анализа и проектирования мобильного приложения были достигнуты следующие результаты:

- **Отказ от сторонних сервисов:** весь путь заявки от подачи до допуска к турниру проходит в одном месте с понятными статусами.
- **Безопасность персональных данных:** справки, полисы ОМС и согласия загружаются и проверяются прямо в приложении без риска утечек через соцсети.
- **Проработанная проектная документация:** подготовлен полный комплект требований, схем (UML, UI Flows) и тест-кейсов, что исключило разночтения при разработке клиентской части.
- **Реальная польза для заказчика:** продукт прошел приемочное тестирование и официально внедрен в деятельность Федерации фиджитал спорта Санкт-Петербурга (подтверждено актом о внедрении).
